# Reference material

Not fixtures, and not gates. Historical artifacts kept for comparison.

## `old-index.md`

The wiki page this project replaces, captured from
`gist.github.com/Sanfam/6b96410eaf58434f966eeae5156e791d` on 2026-09-01. The
script that generated it went offline and the page has been decaying since.

**Treat it as a soft reference, not a specification.** It is substantially out
of date — measured 2026-09-01, it lists 739 unique Entities against a live
Catalog of 1,253, and its names predate at least one known rename. Its value is
as a foundational comparison: what the community used to have, and what the
replacement adds. It is deliberately not wired into the sync or into CI, so a
stale page can never fail a build or hold the Catalog back.

It also contains 746 entry lines for those 739 Entities — the page listed seven
of them twice.
